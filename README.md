# Marketing Page Analyzer

This is a web-based AI tool that analyzes company marketing pages.

Users can enter a marketing page URL, and the app will generate an automated marketing audit, including:

- Target audience
- Core value proposition
- Customer pain points
- Messaging style
- Strengths and weaknesses
- Conversion improvement suggestions

## Live Demo

https://marketing-page-analyzer-demo-pkym9wepnbucxpicqw3.streamlit.app

## How to Use

1. Open the live demo link.
2. Paste a company marketing page URL into the input box.
3. Click **Analyze Page**.
4. Read the AI-generated marketing analysis report.

## Tech Stack

- Python
- Streamlit
- OpenAI API
- BeautifulSoup
- Requests
- GitHub
- Streamlit Community Cloud

## Project Purpose

This project was built as a small marketing engineering tool. Instead of creating a simple chatbot demo, it provides a practical web app that helps users quickly evaluate the effectiveness of a company’s marketing page.
